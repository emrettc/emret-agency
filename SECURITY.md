# Güvenlik

Emret Agency **yerel öncelikli bir masaüstü uygulamasıdır**. Ajanları bu bilgisayarda
PTY içinde çalıştırır; API anahtarları işletim sisteminin şifreli deposunda
(safeStorage) tutulur ve yalnız ana süreç tarafından okunur.

Bir güvenlik açığı bulursanız herkese açık bir issue açmayın; doğrudan proje
sahibine bildirin.
